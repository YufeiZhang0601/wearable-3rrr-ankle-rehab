# RH1 Parallel IK ROS Demo

This demo lets you command foot-plate `pitch/roll/yaw` values and see the
corresponding `joint1/joint4/joint6` angles in ROS 2/RViz.

## Build

```bash
cd ~/rh1_ws
colcon build --packages-select rh1
source install/setup.bash
```

## Launch RViz demo

```bash
ros2 launch rh1 parallel_ik_pose_demo.launch.py
```

Start with a nonzero pose:

```bash
ros2 launch rh1 parallel_ik_pose_demo.launch.py pitch_deg:=2 roll_deg:=1 yaw_deg:=0
```

## Change pose live

In another terminal:

```bash
source ~/rh1_ws/install/setup.bash
ros2 param set /parallel_ik_pose_demo pitch_deg 5.0
ros2 param set /parallel_ik_pose_demo roll_deg 2.0
ros2 param set /parallel_ik_pose_demo yaw_deg 0.0
```

The node logs the solved motor angles and XM430 position ticks:

```text
foot pitch=2.00 roll=1.00 yaw=0.00 deg ->
joint1=14.00 deg tick=2207; joint4=20.50 deg tick=2281; joint6=10.50 deg tick=2167
```

## Important safety note

The default file `config/parallel_ik_autogenerated.json` is fully automatic and
unverified. It is intended for visualization and software bring-up. Use low
angles, low speed, and current limits before using any generated IK output on
real XM430-W350-R motors.
